■ ShinEraTenseiP 同期アプリ

ShinEraTenseiP の本体と口上を gitgud から取得し、ゲームフォルダを最新にするツールです。
「まとめて更新」ボタン一つで、取得（差分だけ）→ ゲームフォルダへの同期まで行います。
セーブデータや設定はそのまま残ります。


■ 必要なもの
・.NET 8 デスクトップ ランタイム（x64）
  https://dotnet.microsoft.com/ja-jp/download/dotnet/8.0
・Git for Windows（推奨）
  https://gitforwindows.org/
  入っていれば、前回からの差分だけを取得します（数秒〜数十秒）。
  無くても動きますが、毎回 zip を丸ごとダウンロードするので時間がかかります。


■ フォルダの中身
ShinEraTenseiP同期アプリ.exe … アプリ本体
config.txt                   … 設定（無ければ起動時に作られます）
本体\                        … 本体の最新版（gitgud: bazzile/eramegaten_p）
口上\                        … 口上の最新版（gitgud: bazzile/eramegatenpKOJO）
追加ファイル\                … ゲームに上乗せするファイル（追加画像など）
work\                        … ログ（同期アプリ_ログ.txt）、同期で消したファイルの退避先（削除済み\）、zip の一時置き場

※「本体」「口上」は更新のたびに配布元と同じ中身に戻ります。ここは手で編集しないでください。
※ exe 一つだけ置いても動きます（設定もフォルダも必要なときに作られます）。


■ 使い方
1. exe を起動します。
   同期先は、隣に ShinEraTenseiP フォルダがあれば自動で入ります。
   違う場所なら「参照...」で、ゲームの ShinEraTenseiP フォルダを選んでください。
2. 「まとめて更新（本体＋口上＋同期）」を押します。
3. 消すファイルがあるときだけ確認が出ます。ログで内容を確認してから OK を押してください。

初回の同期だけ、全ファイルの中身を比べるので数分かかります。2回目からは数秒です。


■ ボタン
まとめて更新         … 本体・口上を取得してからゲームフォルダへ同期します
本体・口上を更新     … このフォルダの「本体」「口上」だけを最新にします（ゲームは触りません）
同期                 … ゲームフォルダを 本体 → 口上 → 追加ファイル の順に重ねた中身と同じにします
追加画像 zip を取り込む … zip を「追加ファイル」へ取り込みます（ウィンドウへのドロップでも可）
追加ファイルを開く   … 追加ファイルのフォルダを開きます
ゲームを起動         … 左の欄の exe（Emuera.exe / EmueraEX.exe など）を起動します
口上も入れる         … 外すと、次の同期で口上のファイルがゲームから消えます
まとめて更新のあと起動 … チェックすると、更新が終わったらそのままゲームを起動します
詳細設定             … 取得元、保存先、git の場所、追加画像の配布元、触らない場所を変えられます
同期で消したファイル（退避先） … 同期でゲームフォルダから消したファイルの退避先を開きます
ログ                 … ログファイル（work\同期アプリ_ログ.txt）を開きます


■ 同期で消すもの・残すもの
同期すると、ゲームフォルダは「本体 → 口上 → 追加ファイル」を重ねたものと同じになります。
配布元で削除・改名されたファイルは、ゲームフォルダからも消えます。
消したファイルは捨てずに work\削除済み\日時\ に元の並びで退避します（直近 10 回分）。

次のものは消しません。
・ゲームフォルダ直下のファイル（EmueraEX.exe、emuera.config など自分で置いたもの）
・「触らない場所」に入っている場所（初期値）
    .git / Data/sav / Data/debug / Data/*.config / Data/*.profile / Data/profile
    Data/setting_user.json / Data/resources/画像_自家製 / *.log / *.dat / console_history.json

自分で追加した画像やファイルを残したいときは、次のどちらかにしてください。
・「追加ファイル」に、ゲームフォルダと同じ並びで置く
    例: 追加ファイル\Data\resources\50_依頼画像\…
・詳細設定の「触らない場所」に追加する
追加ファイルは本体・口上より優先されます。同じ名前のファイルがあれば追加ファイルの方が入り、ログにその旨が出ます。


■ 追加画像について
追加画像（ニカイア動画のイベント画像など）は本体とは別に配布されています。
  https://uu.getuploader.com/eraMegaten_P/ （DL パスワードが必要）
落とした zip を「追加画像 zip を取り込む」で取り込むと、次の同期でゲームに入ります。
zip の外側のフォルダ（[0.4.11]ShinEratenseiP_追加画像 など）は自動で外れ、Data\resources\… に収まります。
※ このアップローダー（uploader.jp）は 2026/11/25 にサービスを終了する予定です。
  配布元が移ったら、詳細設定の「追加画像の配布元」を新しい URL に変えるとリンク先が変わります（空にするとリンクは消えます）。
  zip の取り込み自体は配布元に関係なく使えます。


■ 注意
・ゲームを起動したまま同期すると、書き換えに失敗することがあります（起動中なら確認が出ます）。
・ERB や CSV を改造する場合は、ゲームフォルダを直接編集しないでください。
  「追加ファイル」に置くか、「触らない場所」に入れないと、同期で元に戻ります。
・初めて使う前に、セーブデータ（Data\sav）のバックアップを取っておくと安心です。
